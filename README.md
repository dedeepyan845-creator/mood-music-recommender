# 🎵 Mood Music Player
A simple Flask-based web application where users can manually select their mood and listen to matching songs from a playlist.

## About
This project allows users to choose a mood like Happy, Sad, Angry, Relaxed, Motivated and plays songs based on the selected mood. It is built using Flask and demonstrates basic web development using Python and simple UI.

## Features
- Manual mood selection
- Plays songs based on mood
- Simple and clean UI
- Lightweight Flask app

## Tech Stack
- Python
- Flask
- HTML
- CSS

## How to Run

Install Flask:
pip install flask

Run the app:
python app.py

Open in browser:
http://127.0.0.1:5000/

## Working
- User selects a mood
- User selects the song
- Song plays from local files or links
